# Om Wagale — Personal Portfolio

A personal portfolio website showcasing my skills, projects, resume, and experience in technology and data science.

## 🌐 Live Website

https://omwagale.github.io/

## 📌 About

This portfolio was developed as part of a GitHub Pages experiment to understand:

* Static website development
* Git and GitHub version control
* Repository management
* GitHub Pages deployment

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages

## 📂 Website Sections

* **Home** — Introduction and profile
* **About** — Personal and academic information
* **Skills** — Technical skills and technologies
* **Projects** — Projects and practical work
* **Resume** — Resume and professional information
* **Contact** — GitHub, LinkedIn, and email information

## 🚀 Deployment

The website is deployed using **GitHub Pages** from the `main` branch.
